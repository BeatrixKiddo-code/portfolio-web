Jak neplatit za hosting:
Statické weby zdarma na Netlify, GitHub Pages a Cloudflare (2026)

Autor: Žaneta Janáčová · 25. února 2026 · 6 min čtení

Klasický hosting pro WordPress stojí 1 200–2 500 Kč ročně. Pro statický web (HTML/CSS/JS) existují platformy, kde je hosting zcela zdarma – bez omezení doby, s vlastní doménou a HTTPS certifikátem v ceně.

Proč je hosting pro statické weby zdarma?

Statický web se skládá z pevných souborů: HTML, CSS, JavaScript a obrázků. Server nemusí nic generovat, jen odeslat soubory. To je extrémně levné a jednoduché na provoz, proto si to mohou velké technologické firmy (Netlify, GitHub/Microsoft, Cloudflare) dovolit nabídnout zdarma a tím přilákat vývojáře ke svým placeným prémiových službám.

Naopak WordPress vyžaduje PHP server a MySQL databázi. To jsou výpočetní prostředky, které hosting musí platit. Proto je klasický hosting zpoplatněn.

Podmínka: musíte mít statický web

Bezplatný hosting funguje pouze pro statické weby (čistý HTML/CSS/JS). WordPress, Joomla nebo jiné CMS systémy s databází na těchto platformách nespustíte. Pokud máte WordPress a chcete ušetřit na hostingu, řešením je převod na statický web.

Srovnání tří nejlepších bezplatných platforem

Doporučeno pro začátečníky

Netlify

Nejkomfortnější platforma s přehledným vizuálním rozhraním. Nepotřebujete znát Git, soubory můžete nahrát přímo přetažením (drag & drop). Součástí bezplatného plánu jsou i kontaktní formuláře (do 100 odeslaných zpráv/měsíc) a okamžité nasazení při každé změně souboru.

  • 100 GB přenesených dat/měsíc zdarma
  • Vlastní doména + automatické HTTPS
  • Formuláře (100 zpráv/měsíc) v bezplatném plánu
  • Deploy přes drag & drop nebo GitHub
Zdarma pro vývojáře

GitHub Pages

Ideální volba pro weby spravované přes Git. Každý veřejný repozitář na GitHubu lze jedním klikem publikovat jako web. Výhodou je přímá integrace s vývojovým workflow, každý commit automaticky aktualizuje web.

  • Neomezená šířka pásma pro veřejné repozitáře
  • Vlastní doména + HTTPS
  • Automatický deploy při každém Git commitu
  • Doporučeno: znalost základů Gitu
Nejrychlejší CDN

Cloudflare Pages

Cloudflare provozuje jednu z největších globálních sítí na světě, takže web se načítá rychle odkudkoli. Bezplatný plán nemá omezení šířky pásma. Hodí se pro projekty s vyšší návštěvností nebo mezinárodním dosahem.

  • Neomezená šířka pásma
  • Globální CDN (200+ datových center)
  • Vlastní doména + HTTPS
  • Deploy přes GitHub nebo GitLab

Jak nastavit Netlify krok za krokem

Pro většinu živnostníků a malých firem doporučuji Netlify. Je nejjednodušší na nastavení a nevyžaduje znalost programování.

1

Nahrajte soubory na GitHub

Zaregistrujte se na github.com (zdarma) a vytvořte nový repozitář (tlačítko „New repository"). Pojmenujte ho například muj-web a nastavte jako veřejný. Nahrajte do něj všechny soubory svého webu (index.html, style.css, script.js, složku images).

2

Vytvořte projekt na Netlify

Zaregistrujte se na netlify.com přes GitHub účet. Klikněte na „Add new site" → „Import an existing project" → vyberte GitHub → vyberte svůj repozitář. Pro čistý statický web nevyplňujte žádný build příkaz. Klikněte „Deploy site".

3

Web je online – přidejte vlastní doménu

Netlify vám vygeneruje adresu ve formátu nahodny-nazev.netlify.app. Máte-li vlastní doménu, přejděte do Site settings → Domain management a přidejte ji. Netlify vám ukáže, jaké DNS záznamy upravit u registrátora domény. HTTPS certifikát se aktivuje automaticky do 24 hodin.

4

Každá změna se publikuje automaticky

Od teď platí: cokoliv nahrajete na GitHub, Netlify to automaticky nasadí na web. Žádné FTP, žádné ruční nahrávání. Stačí uložit soubor na GitHub a za 30 sekund je změna živě.

Časté otázky

Opravdu je hosting na Netlify nebo GitHub Pages zdarma?

Ano, pro statické weby je hosting na Netlify a GitHub Pages zcela zdarma bez časového omezení. Netlify nabízí 100 GB přenesených dat/měsíc – pro běžný prezentační web naprosto dostačující.

Mohu na bezplatném hostingu používat vlastní doménu (vasweb.cz)?

Ano. Na Netlify i GitHub Pages připojíte vlastní doménu zdarma. Platíte pouze registraci domény u registrátora – přibližně 200–400 Kč ročně. HTTPS certifikát se nastaví automaticky přes Let's Encrypt.

Mohu na těchto platformách provozovat WordPress?

Ne. Netlify, GitHub Pages ani Cloudflare Pages nepodporují PHP ani MySQL databáze. WordPress na nich nepůjde spustit. Řešením je převod WordPress webu na statický, pak hosting bude zdarma.

Jak funguje kontaktní formulář na statickém webu?

Statický web nemá vlastní backend pro zpracování formulářů. Řeší se to třemi způsoby: 1) Netlify Forms (do 100 odeslaných zpráv/měsíc zdarma). 2) Formulářové služby jako Formspree nebo EmailJS (mám ověřeno v praxi). 3) Jednoduchý odkaz mailto:. Na všech svých projektech používám Formspree.

Kolik celkem ušetřím oproti klasickému hostingu?

Klasický hosting pro WordPress stojí 1 200–2 500 Kč ročně. Po přechodu platíte jen doménu (200–400 Kč). Roční úspora: 1 000–2 100 Kč. Za 5 let: 5 000–10 500 Kč.

Chcete web zdarma na Netlify?

Postavím vám statický web, který nasadím na Netlify nebo GitHub Pages. Hosting pak máte zdarma navždy. Platíte jen doménu. Konzultace je bezplatná a nezávazná.
