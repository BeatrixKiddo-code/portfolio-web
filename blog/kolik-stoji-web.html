Kolik stojí web v roce 2026:
Šablona, WordPress nebo web na míru?

Autor: Žaneta Janáčová · 15. března 2026 · 7 min čtení

„Kolik stojí web?" – nejčastější otázka, kterou dostávám. Odpověď závisí na tom, jakou cestou půjdete. Šablonový stavitel vás může vyjít dráž než web na míru, jen to na první pohled není vidět. Ukážu vám reálná čísla za 1, 3 i 5 let.

Tři cesty k firemnímu webu

Při pořizování webu máte v zásadě tři možnosti: šablonový stavitel (Wix, Squarespace, Webnode), WordPress nebo web na míru. Každá cesta má jiné vstupní náklady, jiné roční provozní náklady a jiný výsledek.

Problém je, že reklamy na Wix nebo Squarespace ukazují ceny od 5–8 dolarů měsíčně. WordPress je „zadarmo". A tak se mnozí živnostníci rozhodnou pro zdánlivě levnější variantu, aby po třech letech zjistili, že za web zaplatili víc, než by stál web na míru.

Celkové náklady vs. vstupní cena

Vstupní cena je jen část příběhu. Web na míru může stát více jednorázově, ale za 3–5 let vás celkově vyjde levněji než předplatné na Wixu nebo provoz WordPressu. Přesná čísla najdete v tabulce níže.

Šablonový stavitel: Wix, Squarespace, Webnode

Pozor na skryté náklady

Jak to funguje

Zaregistrujete se, vyberete šablonu, přetáhnete bloky a web je hotov. Zní to skvěle a pro první krůček skutečně je. Platíte měsíční nebo roční předplatné, které zahrnuje hosting i šablonu. Web ale nikdy skutečně nevlastníte, bez aktivního předplatného se web vypne.

  • Wix Business: cca 350–550 Kč/měsíc (4 200–6 600 Kč/rok)
  • Squarespace Personal: cca 400–600 Kč/měsíc (4 800–7 200 Kč/rok)
  • Webnode Standard: cca 200–400 Kč/měsíc (2 400–4 800 Kč/rok)
  • Doména: 200–400 Kč/rok navíc (u levnějších plánů)
  • Prémiové šablony nebo pluginy: 500–3 000 Kč jednorázově

Wix a Squarespace jsou vhodné pro rychlé testování nápadu nebo sezónní projekt. Pro seriózní firemní prezentaci mají zásadní nevýhody: pomalejší načítání (generovaný kód je nafouklý), omezená SEO kontrola (strukturovaná data, vlastní meta tagy) a hlavně – cena neklesá, roste. Každý rok platíte znova.

WordPress: zdarma, ale ne tak úplně

Vyšší skryté náklady než se zdá

Jak to funguje

WordPress samotný je open-source a zdarma. Ale k provozu potřebujete hosting s PHP a MySQL databází, šablonu, pluginy a pravidelnou údržbu. Tohle vše stojí peníze nebo čas. Navíc jsou WordPress weby terčem automatizovaných útoků a bez pravidelných aktualizací je to bezpečnostní riziko.

  • Tvorba webu (agentura nebo freelancer): 15 000–80 000 Kč jednorázově
  • Hosting s databází: 1 200–2 500 Kč/rok
  • Prémiová šablona: 1 500–3 000 Kč jednorázově
  • Pluginy (SEO, formuláře, bezpečnost): 500–3 000 Kč/rok
  • Správa a aktualizace: 1 200–6 000 Kč/rok nebo vlastní čas

WordPress má smysl, pokud opravdu potřebujete redakční systém – tedy chcete sami přidávat desítky článků nebo produktů bez programátora. Pro statickou firemní prezentaci (5–10 stránek, které se nemění každý týden) je to zbytečně drahý a komplikovaný nástroj.

Web na míru: statický HTML/CSS/JS

Nejnižší náklady za 3+ roky

Jak to funguje

Web napsaný ručně v čistém HTML, CSS a JavaScriptu přímo pro váš projekt. Žádná šablona, žádné zbytečné skripty, žádná databáze. Výsledkem je nejrychlejší možný web (Lighthouse skóre 95–100), hosting zdarma na Netlify nebo GitHub Pages a nulová pravidelná údržba.

  • Tvorba webu: 6 000–25 000 Kč jednorázově (dle rozsahu)
  • Hosting: 0 Kč/rok (Netlify, GitHub Pages)
  • Doména: 200–400 Kč/rok
  • Údržba a aktualizace: 0 Kč (žádné pluginy, žádné zranitelnosti)
  • Změny obsahu: domluvou, jednorázově

Kdy která varianta dává smysl

Wix nebo Squarespace – kdy ano

Šablonový stavitel volte, pokud testujete nápad a nevíte, zda projekt přežije rok, chcete mít web do týdne bez jakéhokoliv programování a nemáte zájem investovat do dlouhodobého řešení. Pro hobby projekt nebo jednoduchou landing page je to fér volba.

WordPress – kdy ano

WordPress má smysl tehdy, když potřebujete redakční systém – tedy pravidelně přidáváte desítky článků, správu produktů nebo správu obsahu přenecháváte někomu, kdo neumí programovat. E-shop na WooCommerce, zpravodajský portál, rozsáhlý blog. Pro statickou prezentaci 5–8 stránek je WordPress přestřelený.

Web na míru – kdy ano

Web na míru je ideální pro živnostníky a malé firmy, kteří chtějí seriózní firemní prezentaci, která funguje rychle, vypadá profesionálně a nestojí nic na provoz. Obsah se nemění každý týden, web slouží jako vizitka a zdroj poptávek. Tohle je přesně profil, pro který statické weby vznikly.

Moje zkušenost z praxe

Většina mých klientů přichází s WordPress webem nebo Wixem, který buď načítá pomalu, nebo je drahý na provoz. Po přechodu na statický web mají Lighthouse skóre nad 95, hosting zdarma a nulové starosti s aktualizacemi. Přechod jim ušetří tisíce korun ročně. Více o převodu WordPressu na statický web najdete v tomto článku.

Co ovlivňuje cenu webu na míru

Cena webu na míru se liší podle rozsahu a složitosti. Orientační přehled, s čím počítat:

  • Jednoduchá vizitkový web (1–3 stránky, kontaktní formulář): od 6 000 Kč
  • Prezentační web (5–8 stránek, portfolio, ceník): 10 000–18 000 Kč
  • Rozsáhlý web s blogem nebo galerií (10+ stránek): 18 000–30 000 Kč
  • Převod existujícího WordPress webu na statický: od 6 000 Kč

Do ceny je vždy zahrnuto: nastavení hostingu na Netlify nebo GitHub Pages (hosting pak máte zdarma), napojení vlastní domény, HTTPS certifikát, optimalizace rychlosti a základní SEO nastavení.

Časté otázky

Kolik stojí jednoduchý web pro živnostníka?

Záleží na cestě. Wix nebo Squarespace vás vyjde na 4 000–8 000 Kč ročně (bez vstupní práce). WordPress web u agentury stojí 15 000–50 000 Kč jednorázově plus hosting a údržba. Web na míru pořídíte od 6 000 Kč s hostingem zdarma a nulovou roční údržbou.

Je Wix dobrá volba pro firemní web?

Pro dočasné nebo hobby projekty ano. Pro seriózní firemní prezentaci má Wix limity: pomalejší načítání oproti statickým webům, omezená SEO kontrola a hlavně – bez předplatného se web vypne. Web na Wixu nevlastníte.

Proč je WordPress dražší na provoz, než se zdá?

WordPress sám o sobě je zdarma, ale hosting stojí 1 200–2 500 Kč/rok, prémiové šablony 1 500–3 000 Kč, pluginy 500–3 000 Kč/rok a pravidelné aktualizace zabírají čas nebo platíte za správu. Celkové náklady za 5 let snadno překročí 30 000 Kč.

Co je web na míru a čím se liší od šablony?

Web na míru je napsán ručně v HTML, CSS a JavaScriptu přímo pro váš projekt. Žádná šablona, žádné zbytečné funkce navíc. Výsledek je rychlejší (Lighthouse skóre 95–100), bezpečnější (bez databáze a pluginů) a s hostingem zdarma na Netlify nebo GitHub Pages.

Kdy se web na míru vyplatí víc než WordPress?

Pro prezentační weby živnostníků a malých firem téměř vždy. Web na míru je levnější na provoz, rychlejší a bezpečnější. WordPress má smysl, pokud potřebujete e-shop, blog s desítkami článků nebo klient chce sám přidávat obsah bez programátora.

Chcete vědět, kolik by stál web přesně pro vás?

Pošlete mi pár řádků o svém projektu – jaký web potřebujete, kolik stránek a co má umět. Obratem pošlu nezávaznou nabídku. Konzultace i nabídka jsou zdarma.
